Totbereich: der unbedruckte Streifen oben auf dem Etikett – zwischen Druckkopf und Abrisskante liegt Papier, das schon durch ist. Einmal am Ausdruck messen und eintragen; das Layout wird dann so weit gekürzt, dass alles auf ein Etikett passt.
Rückzug: holt diesen Streifen zurück (8 Punkte = 1 mm), dann passt wieder mehr drauf. Nicht jeder Drucker kann rückwärts fahren – klein anfangen und testen; verschluckt sich der Vorschub, wieder auf 0.

Wartung

Bestand aus Version 1 übernehmen

Drei Dateiformen werden erkannt: eine .csv wie sie SELECT * FROM current_inventory im ersten Projekt liefert, eine einzelne .json von der SD-Karte (inventory.json oder removed_items.json aus /scanner_backup/) oder der ganze Ordner als .zip. Etiketten mit bereits vorhandener Nummer werden übersprungen – ein wiederholter Import nach einem Abbruch ist also gefahrlos.
