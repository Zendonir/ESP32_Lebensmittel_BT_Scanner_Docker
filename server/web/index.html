Wer beim Einlegen einer neuen Rolle die Zahl der Etiketten einträgt, sieht hier und am Terminal, wann die Rolle zur Neige geht.

Einrichten

Einmal für jede neue Etikettensorte oder einen neuen Drucker. Jede Änderung wird sofort gespeichert.

1 Etikett

Zeilen – von oben nach unten. Leere Angaben fallen weg. Passt nicht alles, wird von unten gekürzt; MHD und Code bleiben immer.

2 Papierlauf

Ablauf je Etikett: Rückzug → Etikett in der eingestellten Höhe → Nachlauf. Fest eingestellt: 9600 Baud · 32 Zeichen je Zeile · Rückzug mit ESC K · Bildmodus B (ESC * 33).

Drucker testen – nur für einen anderen Drucker

Bestand aus Version 1 übernehmen

– nur einmal beim Umstieg nötig

Drei Dateiformen werden erkannt: eine .csv wie sie SELECT * FROM current_inventory im ersten Projekt liefert, eine einzelne .json von der SD-Karte (inventory.json oder removed_items.json aus /scanner_backup/) oder der ganze Ordner als .zip.
